Lab 2 – Installing Fluent Bit on Kubernetes (k3s)

Lab Goal

To deploy Fluent Bit onto a Rancher Desktop Kubernetes (k3s) cluster running on your local machine, where it collects container logs alongside a log generating workload.

Kubernetes – Installing Rancher Desktop tooling

Deploying Fluent Bit onto a Kubernetes cluster is going to be demonstrated here using the open source project Rancher Desktop, which provides a local single node Kubernetes (k3s) cluster. It's assumed you have already installed Rancher Desktop with Kubernetes enabled (this provides the rdctl commandline tooling and a rancher-desktop kubeconfig context).

The install runs entirely against the headless backend using rdctl, kubectl, and helm, so the Rancher Desktop UI never needs to be opened.

Kubernetes – Using the easy install project

Deploying onto your cluster can be done in just a few steps with our Fluent Bit Easy Install project. This uses a simple automated installation script that validates the prerequisites (rdctl, Helm v3+, and kubectl v1.32+) for you.

The Fluent Bit Easy Install project takes just 3 steps to a running deployment:

  1. Download and unzip the project.
  2. Run the init.sh rancher file in a console.
  3. Check the pods and follow the collected logs on the cluster.

Intermezzo – What to do with any failures?

At any time in the workshop should you encounter failures, during installation, testing, data population, or build results. Don't worry, this can be rerun any time after you fix any problems reported. The script is idempotent, so rerun it from the project root directory: 
							
								$ ./init.sh rancher

Intermezzo – Shutdown your cluster environment

At anytime in the workshop you can pause and come back later. To remove just this demo (leaving the rest of your Rancher Desktop cluster intact): 
							
								$ helm --kube-context rancher-desktop uninstall fluent-bit -n logging && \
								    kubectl --context rancher-desktop delete namespace logging
To bring down the whole Rancher Desktop setup when you are finished, stop the backend from the tray menu, or shut it down headlessly with rdctl: 
							
								$ rdctl shutdown
