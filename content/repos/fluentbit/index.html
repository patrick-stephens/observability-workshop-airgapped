Workshop

Getting started with cloud native telemetry pipelines

This workshop will guide you through telemetry pipelines with the open source project Fluent Bit, what it is, a basic installation, and setting up a first pipeline project.
Needed for Kubernetes install: Rancher Desktop (k3s)
Needed for container install: Podman or Docker
Needed for source install: cmake, openssl, and bison

Labs are based on Fluent Bit v5.1, Prometheus v3.13, OpenTelemetry Collector v0.159, OpenSearch v3.3.1, and OpenSearch Dashboard v3.3.0
