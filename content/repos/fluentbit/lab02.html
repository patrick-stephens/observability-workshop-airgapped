Lab 2 – Installing Fluent Bit

Lab Goal

To install and run a basic Fluent Bit pipeline on your local machine.

Reporting any workshop issues

In the next slide you will choose between three installation paths: from the source project, using a container image, or deploying onto a Kubernetes (k3s) cluster with Rancher Desktop. Depending on your OS (Windows or Unix-based), you are going to use installation scripts that attempt to automate the process. Should you encounter any issues, during installation or elsewhere in this workshop, please report them using these links as is appropriate for your issue(s):

  • Workshop problems - click here to report

Options for installing Fluent Bit

There are several ways to install Fluent Bit, so please click on the option you want to use for the rest of this workshop:
  • Installing in a container using Podman (preferred)
  • Installing from the source code
  • Installing on Kubernetes (k3s) using Rancher Desktop
