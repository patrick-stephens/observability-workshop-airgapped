Workshop

Getting started with open dashboards and visualization

This workshop will guide you through the open source dashboard and visualization project Perses, what it is, a basic installation, and building your first dashboard.
Needed for kubernetes install: Rancher Desktop (k3s), Helm
Needed for container install: Podman or Docker
Needed for source install: Go v1.26+, Node.js v22+, npm v10+

Based on Perses v0.54, Prometheus 3.13, and Node Exporter 1.12
