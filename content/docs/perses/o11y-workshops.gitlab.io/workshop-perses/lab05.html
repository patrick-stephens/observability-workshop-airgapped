Lab 5 - Building your first dashboard

Lab Goal

To install a Prometheus data source for Perses to query, then build your first basic dashboard from the basic template you created in the last lab.

First dashboard - Starting point for this lab

In the previous lab you explored the sections and elements used in a dashboard specification resource. To start this lab (you should have done previously), open a browser to the project workshopproject as shown:

First dashboard - We need a data source

If we just open our dashboard project now, there will be no data as the data source is expecting to find a Prometheus instance. Before starting to build out our first basic dashboard, we will install, configure, and run a Prometheus instance collecting data from itself and a Node Exporter instance.

How this lab is organised

This lab comes in two parts. On the next slide you pick how you want to install the Prometheus data source, which takes you off to that installation path. Every one of those paths ends by sending you on to lab 5b, where you build the dashboard itself.

You do not come back to this page, so pick your path and keep going.

Options for installing a data source

Perses needs something to query, so please click on the option you want to use, matching how you installed Perses back in lab 2:
  • Installing in containers using Podman (preferred)
  • Installing the local binaries
  • Installing on Kubernetes (k3s) with Helm
Installed Perses from source in lab 2? Take either the Podman or the local binaries path, both work alongside it. Using the online demo sandbox you can't reach our Prometheus install here, so skip this lab.
