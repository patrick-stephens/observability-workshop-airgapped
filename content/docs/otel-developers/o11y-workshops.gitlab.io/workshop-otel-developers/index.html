OpenTelemetry for Java Developers

This workshop will guide you through setting up OpenTelemetry (OTel) and instrumenting a Java application locally to collect and analyze trace data.
Prerequisites: Podman v5+, Java 21, Maven 3.8+, and Rancher Desktop (k3s)
Based on OpenTelemetry Java SDK v1.65, Java Agent v2.30, Jaeger v1.76, and Prometheus v3.13.1

OpenTelemetry Java Tracing Demo Application

In this workshop we'll be using a Java HTTP server application with these endpoints:

EndpointMethodDescription
/GETPage view counter
/rolldiceGETRandom dice roll (1-6)
/doggoGETRandom dog image from dog.ceo API
/doggoPOSTSearch for specific breed image

Server runs on: http://localhost:9999
